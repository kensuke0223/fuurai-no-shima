# 風来の島（プロトタイプ）

ブラウザで遊べる、ターン制ダンジョン探索ゲームです。PCは矢印キー/WASD、スマホは画面の方向ボタンで操作できます。

## すぐに遊ぶ（オフライン）
`index.html` をブラウザで開いてください。移動、敵との戦闘、拾ったアイテムの使用、階段での階層移動ができます。

## オンライン協力プレイを試す
必要：Node.js 18以降

1. このフォルダで `npm install` を実行
2. `npm start` を実行
3. 同じPCならブラウザで `http://localhost:8080` を開く
4. 別のPCやスマホから遊ぶ場合は、サーバーをホストしているPCのLAN IPアドレスにアクセス（例 `http://192.168.1.20:8080`）
5. 画面の「WebSocket URL」に `ws://localhost:8080`（別端末なら `ws://192.168.1.20:8080`）を入力し、同じ部屋コードで接続

インターネット越しに遊ぶには、サーバーを公開ホストへデプロイし、HTTPS/WSSを設定する必要があります。ファイアウォールやルーターの設定も必要になる場合があります。

## 現在の試作の制限
- オンライン機能はWebSocketで状態を中継するプロトタイプです。正式版に必要なサーバー権威型のゲーム状態管理、同期競合対策、認証、切断復帰、レート制限は未実装です。
- 複数人で同じゲーム状態を同時更新すると、状態が上書きされる場合があります。公開運用前にサーバー側でターン処理を一元管理する必要があります。
- グラフィックは絵文字とCanvasの簡易描画です。『風来のシレン』の公式作品ではなく、オリジナルの試作です。
